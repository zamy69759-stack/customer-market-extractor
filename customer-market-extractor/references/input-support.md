# 输入支持与降级

- 直接支持：`.txt`、`.md`、`.csv`、`.html`、`.eml`、`.srt`、`.vtt`、`.json`。
- 可选本地依赖：`.docx`（python-docx）、`.xlsx`（openpyxl）、文本型 `.pdf`（pypdf）。缺包时记录“部分成功/缺少解析器”。
- `.msg` 需要 extract-msg；`.pptx` 需要 python-pptx。未安装时安全失败并保留文件指纹。
- 图片保留路径与文件名，默认不 OCR。只有获得授权且检测到本地 OCR/视觉能力后才处理；不清晰内容标“无法确认”。
- 音频默认不转写。用户明确授权后才可使用已检测到的本地或云转写能力。
- 扫描 PDF 无文字层时标记“需要 OCR”，不得声称已读取。

每个文件都必须在解析报告中记录：路径、类型、SHA-256、状态（成功/部分成功/失败）、原因、证据定位方式。
